# SuperSeedance Guides

Practical Seedance video guides, complete prompts and original examples from [SuperSeedance](https://superseedance.si/en).

[简体中文](README.zh-CN.md)

SuperSeedance is an independent AI video workspace for creating from text or images with Seedance 2.5. It brings prompts, private reference images, credit estimates and saved videos into one place, with an interface in 20 languages.

## Watch the original examples

The [prompt guide](https://superseedance.si/en/blog/seedance-prompt-guide#motion-examples) pairs eight original Seedance 2.5 clips with their complete prompts and generation settings: rainy-night parkour, a cloud-city flight, anime skating, an ink-wash whale, solo dance, clay animation, a forest adventure and liquid metal.

The submitted settings for these eight examples were text-to-video, six seconds, 720p, 16:9, no audio and no draft mode. Preview edits do not change those source-generation settings. A prompt is a reproducible starting point; it does not guarantee an identical output.

## Using SuperSeedance

Choose text or image input, describe one scene and its movement, select supported settings, review the studio-credit quote, then submit and track the task in My Creations. Generation requires a verified account, sufficient credits and an available service.

Credit purchases are not yet available as of October 24, 2026. Existing guides and public examples remain accessible. Check the [pricing page](https://superseedance.si/en/pricing) for the current purchase status.
